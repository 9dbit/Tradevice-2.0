# Tradevice home-screen icon

Reconstructed the supplied orange-arrow reference as crisp SVG paths on opaque near-black. Exports: Apple touch icon 180px, PWA 192px and 512px, and 1024px master PNG. The artwork stays inside the maskable safe area; operating systems supply their own corner masks.

Added the application manifest, standalone launch at /master, Apple web-app metadata, and versioned icon URLs. No service worker, offline telemetry cache, authentication change or trading behavior change.

Validation: production build passed; local HTTP checks confirmed Apple touch and manifest head links, standalone manifest/start URL, and all four PNG routes, MIME types and dimensions. Inspected the 512px export visually against the reference. Existing iOS home-screen shortcuts may need to be removed and added again after deployment to refresh their stored icon.

Regenerate assets with `node scripts/render-app-icons.mjs` from the web directory (uses the installed Sharp dependency).
